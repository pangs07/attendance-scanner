# QR Code Attendance Scanner

## Overview

The QR Code Attendance Scanner is a browser-based attendance recording system that uses device cameras to scan QR codes and automatically log attendance records to a Google Sheets backend through Google Apps Script.

The system is designed for rapid attendance taking during formations, meetings, classes, training activities, and other events where personnel are identified using QR codes.

---

## Features

### QR Code Scanning

* Uses the device camera to scan QR codes.
* Supports smartphones, tablets, laptops, and desktop computers with cameras.
* Utilizes the HTML5 camera API through the html5-qrcode library.

### Scanner Activation

Before attendance can be recorded, the scanner must be activated using an authorized Operator QR Code.

Benefits:

* Prevents unauthorized devices from recording attendance.
* Identifies the scanner station being used.
* Allows multiple scanners to operate simultaneously.

### Attendance Recording

For each successful scan, the system records:

* Timestamp (generated by Google Sheets)
* Personnel Serial Number
* Scanner Name

### Duplicate Scan Prevention

The application prevents immediate duplicate scans by ignoring repeated QR code reads until the previous scan has been processed.

### Audio Feedback

A confirmation beep is played whenever attendance is successfully recorded.

### Local Scanner Storage

The following information is stored locally in the browser:

* Scanner Name
* Scanner Token

This allows the scanner to remain activated even after the page is refreshed.

### Scanner Reset

The **Change Scanner** button allows operators to:

* Remove the current scanner token.
* Remove the current scanner name.
* Register a new scanner.

---

## System Workflow

### Initial Setup

1. Open the Attendance Scanner webpage.
2. Enter the scanner name when prompted.

Example:

```
Scanner1
Main Gate
Registration Desk
```

3. Scan the authorized Operator QR Code.
4. The scanner is activated.

---

### Attendance Recording

1. Personnel presents their QR Code.
2. Scanner reads the QR Code.
3. Data is transmitted to Google Apps Script.
4. Attendance is recorded in Google Sheets.
5. A success message and audio confirmation are displayed.

## Configuration

The Google Apps Script endpoint is defined in:

```javascript
const APPS_SCRIPT_URL =
"https://script.google.com/macros/s/XXXXXXXXXXXX/exec";
```

Replace the URL with your deployed Google Apps Script Web App URL.

---

## Security Features

### Operator Authentication

Attendance recording is disabled until an authorized operator QR code is scanned.

### Operator QR Blocking

Operator QR codes cannot be logged as attendance records.

### Local Token Storage

Scanner authorization is stored locally using browser Local Storage.

### Server Validation

All attendance submissions are validated by Google Apps Script before being recorded.
